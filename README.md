A program that writes one original line to /output/entry.txt: the office printer's comeback to the jams, the error codes and the thumps — it has printed 214,000 pages for people who can't find the power button, and yet it still gets thumped like it's the broken one.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
